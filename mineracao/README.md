# 🤖 Aprendizado de Máquina

Este repositório contém os notebooks desenvolvidos ao longo da disciplina de **Aprendizado de Máquina**, ministrada com foco estatístico e prático, utilizando **Python** no **Google Colab**.

## 📘 Conteúdo abordado

A disciplina combina teoria e prática para introduzir os fundamentos do aprendizado supervisionado e não supervisionado, incluindo:

* 🔢 Regressão Linear e Polinomial
* 📈 Classificação com Regressão Logística
* 📊 K-Nearest Neighbors (KNN)
* 🌲 Árvores de Decisão e Random Forests
* 🧹 Pré-processamento e Validação Cruzada
* 📉 Regularização com Ridge e Lasso
* 📦 Divisão treino/validação/teste
* 🧪 Análise de viés-variância
* 🧠 Seleção e avaliação de modelos

## 🛠️ Ferramentas e Tecnologias

* Python 3
* Google Colab
* Pandas, NumPy, Matplotlib, Seaborn
* Scikit-learn
* Git e GitHub
